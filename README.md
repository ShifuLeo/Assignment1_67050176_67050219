## แรงบันดาลใจ
เราทั้งสองคนมีความชอบที่เหมือนกันคือ ชอบแมว ดังนั้นเมื่อนึกถึงความทรงจำของเราแล้ว แมวเป็นหนึ่งสิ่งที่โผล่มาแทบในทุกช่วงเวลาของชีวิต
ไม่ว่าจะเป็นช่วงเวลาแห่งความสุข หรือเสียใจ สิ่งมีชีวิตตัวเล็กๆ นี้ก็จะคอยอยู่เคียงข้างเราทั้งสองเสมอ แต่มีพบก็ต้องมีจาก ตลอดเวลา 20 ปี ที่ผ่านมา
ในหลายๆ ครั้งเราก็ต้องทำใจจากลากับเพื่อนตัวน้อยนี้ แต่ถึงแม้พวกมันจะจากไปมันก้จะยังคงอยู่ในความทรงจำ เป็น “MY MEMORIES” ของเราตลอดไป
